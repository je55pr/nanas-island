# Nana's Island - Image Generation Approval Queue

No generated art has been added yet. The prototype uses CSS, Canvas, emoji and a hand-written SVG icon only.

## Pending approval
1. **Island hub / map background** — a warm portrait-friendly island overview with clear empty spaces for Sanctuary, Pavilion, Cottage and future areas. High value because it defines the game's world and visual tone.
2. **African elephant lead** — transparent-background character concept/model sheet, anthropomorphic, expressive and outfit-friendly. Needs design approval before any story illustrations.
3. **Gibbon lead** — transparent-background character concept/model sheet, anthropomorphic, long-armed and expressive, designed to visually contrast the elephant.
4. **Butterfly sanctuary background** — bright glasshouse/garden environment with flower beds and room for live butterfly sprites layered over it.
5. **First story scene / loading splash** — the elephant and gibbon arriving on Nana's Island together. Only worth generating after the two character designs are locked.

## Probably better sourced or reference-led than freely generated
- **Butterfly species art:** markings should be recognisable and biologically plausible. Prefer accurate references, then make simplified game sprites from those references.
- **Flower/host-plant art:** use botanical references so flower-to-butterfly relationships stay credible.
- **Match-3 pieces:** likely best as purpose-built vector/sprite icons for maximum readability at phone size rather than large generated illustrations.

## Temporary prototype art
The current build intentionally uses simple emoji/CSS placeholders for characters, butterflies and scenery so art decisions do not become accidental canon.
